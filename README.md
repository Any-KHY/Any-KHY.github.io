# Any Kwok — Portfolio Website

Personal portfolio website for Any Kwok, Business & Data Analyst based in Auckland, New Zealand.

**Live site:** [any-khy.github.io](https://any-khy.github.io)

---

## Projects Featured

- **Kids Online Brand Exposure Detection Pipeline** — Master's thesis. Multi-model computer vision pipeline (YOLOv11, YOLO-World, EasyOCR, CLIP) processing 700,000+ video frames to detect fast-food brand exposure in children's screen-recorded media.
- **Sales Performance & Pricing Analysis** — End-to-end MySQL and Power BI dashboard for product performance, pricing effectiveness, and profitability analysis.
- **Parkinson's Diagnosis via Voice Analysis** — ML classifier comparison (KNN, Random Forest, SVM) across six voice feature schemes, built in Julia with nested cross-validation.
- **MongoDB Scalable Song Database** — NoSQL database design using a 498,000-track Spotify dataset, covering document modelling, indexing, and query design.
